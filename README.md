# SAM 4.0 — Complete Rebuild

سام ۴٫۰ بازسازی مستقل دستیار شخصی و حرفه‌ای SAM است. این مخزن از سورس و دیتابیس نسخه‌های قبلی استفاده نمی‌کند؛ نیازمندی‌های تثبیت‌شده حفظ شده‌اند.

## وضعیت این بسته
این خروجی، **پایه‌ی قابل توسعه‌ی پروژه** است؛ نه محصول نهایی. رابط اولیه و زیرساخت ساخت اندروید آماده شده‌اند، اما اتصال واقعی هوش مصنوعی، STT/TTS، همگام‌سازی سرویس‌ها، حافظه‌ی پایدار و قابلیت‌های کارخانه هنوز در این بسته پیاده‌سازی نشده‌اند.

## نیازمندی ساخت
- Android Studio سازگار با Android Gradle Plugin 8.13.0
- JDK 17
- Gradle Wrapper از طریق GitHub Actions (Gradle 8.13)
- Android SDK 36

## شروع
1. تمام محتویات ZIP را در ریشه‌ی مخزن `SAM-Android-4.0` بارگذاری کنید.
2. تغییرات را روی شاخه‌ی `main` ثبت کنید.
3. در GitHub به بخش Actions بروید و workflow با نام **SAM Android CI** را بررسی کنید.
4. پس از موفقیت workflow، APK دیباگ از بخش Artifacts قابل دریافت است.

## اصول معماری
- Kotlin و Jetpack Compose
- رابط فارسی و RTL
- منابع داده‌ی دامنه‌ای مستقل؛ SAM مالک اصلی داده‌های سرویس‌های بیرونی نیست.
- کش محلی، صف عملیات، شناسه‌های provider، cursor همگام‌سازی و مدیریت تعارض برای تاب‌آوری
- هیچ کلید API یا رمز عبوری در سورس hardcode نمی‌شود.

## محدوده‌ی کارخانه
تولید، خطوط، ماشین‌آلات، ظرفیت، برنامه‌ریزی، تولید واقعی، توقفات، ضایعات، راندمان، انبار و گزارش‌های تولیدی.

**خارج از محدوده:** منابع انسانی، مدیریت کارکنان، حضور و غیاب، حقوق، دستمزد، کسورات و ارزیابی پرسنل.

## هشدارهای صداقت فنی
- Wake word پس‌زمینه‌ی «سام» تا آزمون واقعی روی Samsung Galaxy S24 Ultra با Android 17 تأییدشده تلقی نمی‌شود.
- قابلیت آفلاین باید برای هر قابلیت جداگانه تعریف و روی دستگاه واقعی سنجیده شود.
- همگام‌سازی دوطرفه‌ی هر سرویس فقط پس از تأیید API رسمی آن سرویس قابل اعلام است.
- این بسته در محیط ساخت Android اجرا نشده است؛ تأیید نهایی build بر عهده‌ی GitHub Actions است.
